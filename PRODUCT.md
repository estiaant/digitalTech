# Digital Technology resources

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users and purpose
Grade 8 learners learning to identify computer hardware, explain its purpose, and distinguish input, processing, output, storage, and communication. The first resource is a desktop-first, interactive computer-building activity for module 1.1, Introduction to Computers.

## Stack
Static website requested by the user. Implementation choice: plain HTML, CSS, and JavaScript; no installation, accounts, APIs, or build step.

## Capabilities and constraints
Start with keyboard and mouse. Within each category, components can be explored and added in any order. Teach RAM alongside processing while explicitly distinguishing temporary memory from secondary storage. Compare HDD and SSD in simple subject-specific language. A graphics card is optional enrichment. Use the supplied textbook as the content authority; do not introduce extra required processing components. Desktop is the initial target. No decision has been made to create a resource for every module.

## Brand commitments
The approved pixel-art references and the original Lospec500 GPL palette are in `assets/design-references/`. Dark green and purple are the school colours. Hardware is the main subject of future assets.

## Evidence on hand
`Grade 8 Content.md`, especially Unit 1.1 and the motherboard summary. Approved girls-school style sheet and exploded tower reference. The generated reference sheets establish appearance; the GPL file establishes exact colours.

## Completion sequence

After all required components have been added, the computer starts up. Learners can shrink it to a laptop and then a smartphone, with brief explanations of miniaturisation, portability, and reduced upgradeability. Draw from textbook content where available and keep explanations short and engaging. Knowledge checks are optional in the first implementation.

## Game presentation

User-approved direction: simple 64×64 pixel art with cosy farming-game-style animation, a visual-novel presentation, large artwork and dialogue banners, and a simple chiptune soundtrack. Selecting a component opens a dedicated discovery scene; it is added only after the learner chooses Add. Remove simulated browser/window framing. Dark green and purple remain the school colours, with more playful pink, lilac, peach, mint and butter-yellow accents.

The processing stage includes motherboard, CPU, and RAM, with an optional graphics card. The user has removed ROM and the system bus from the activity.
