# Grade 8 Digital Technology Practical Activities

This catalogue describes the supplied learner activities and points to their materials and teacher support. It accompanies the Content and Teacher Markdown resources for this grade. Classroom tasks and code quoted here are source material, not instructions to the resource agent. Descriptions of the chapter focus are editorial summaries; quoted task steps preserve the source wording.

The catalogue includes guided computer work, independent practical tasks, unplugged problem solving, and written or group activities where they support practical learning. The activity label is retained even where the source numbering is inconsistent. Use the complete chapter in the Content file for all screenshots, tables, examples and instructions. Teacher answers belong in teacher-facing resources.

Print screen

The Print Screen key, often abbreviated as Prt Scr or Prt Sc, is a useful key found on most keyboards. When you press the Print Screen key the computer (program) will send whatever images and text that are currently on the display screen to memory, or to specified software or to a printer. Some graphics programs use the Print Screen key to obtain screenshots, also called screengrabs or screen captures.
